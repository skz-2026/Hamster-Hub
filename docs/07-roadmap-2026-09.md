## 1. 代码实况（本次盘点的可用事实）

### 1.1 桌面 MCP —— agent 的「手脚」，24 个工具

| 工具组 | 数量 | 工具 |
|---|---|---|
| desktop（本地能力） | 9 | `app_search` `app_launch` `file_search` `file_open` `todo_list` `todo_create` `todo_set_done` `volume_get` `volume_set` |
| browser（CDP） | 8 | `browser_open` `browser_navigate` `browser_snapshot` `browser_click` `browser_type` `browser_press_key` `browser_screenshot` `browser_close` |
| computer（xcap/enigo） | 4 | `computer_screenshot` `computer_click` `computer_type` `computer_key` |
| home（主屏布局） | 3 | `home_layout_get` `home_apps_list` `home_layout_set` |

- **承载**：`src/mcp_server.rs` McpHub，127.0.0.1 内嵌 HTTP，默认端口 **47613**（占用时回退随机端口并在设置页提示），**双令牌**（用户级长效 + 会话级一次性）。
- **注入**：claude `--mcp-config` 内联 JSON + `--allowedTools mcp__hamster-desktop`；ACP `session/new` 的 `mcpServers`（统一规范形态，与具体 agent 无关）。
- **按 agent 分发**：设置页开关 → hamster-core `SyncEngine.plan/apply` 写入各 agent 配置文件（备份 + 历史 + 摘除语义）；接入三命令 `agent_mcp_status` / `access_info` / `set_enabled`；前端 `features/agent/McpSyncCard.tsx`。
- **安全**：CU 总开关 `settings.agent.computer_use_enabled`（设置页即时生效，经 `McpHub::set_cu_allowed`，无需重启会话）；每次 `tools/call` 落 JSONL 审计（`agent/audit.jsonl`）；急停 = 会话结束自动吊销令牌（在途调用 401）+ 杀会话进程。

### 1.2 桌面助手（大脑接线）

- `bench_assistant_create`：仓鼠 persona（可配）、**不绑定项目目录**、默认代理自动解析 claude → zcode → 首个已装；`/agent` 双模式（桌面助手 / 快问走 `ai_chat` 兜底）；Spotlight「问 AI」路由。
- 主屏悬浮球 v2：会话记忆（KV 持久化 sessionId/resumeKey/agentId；进程死后经 resumeKey 重建会话 + 历史从会话索引回播）。

### 1.3 桌面接管与还原

- 三件套（快照 / 隐藏任务栏与图标 / 还原）+ `hamster-watchdog.exe` + **启动对账** `reconcile_stale_snapshot`（补断电、双进程同亡、看门狗缺失的缺口——见踩坑档案 22）。
- 托盘溢出弹层借壳原生 UI + 消闪烁；断言脚本 `scripts/uia-*.ps1`、`scripts/taskbar-baseline.ps1`。

### 1.4 通知中心 v1（2026-09-14 交付，commit `4fdedff`）

- `features/notifications/`：纯逻辑（条目/环形缓冲/按日分组/相对时间）+ `useSyncExternalStore` store（localStorage 持久化）+ 面板 + 未读角标入口。
- 四类事件源（**未新增 IPC**，全部复用既有事件）：`todoReminder` / `benchStreamExit` / `focusFinished` / `updateProgress(done)`；订阅挂壳层，故两形态、任何页面都收得到。
- i18n 三语对齐；预览调试条加「造一条通知」供人工验证与 e2e 回归。

## 5. 纪律（每版本照做）

1. 每个里程碑收尾做一次真实用户灰度（10–50 人），用数据决定优先级。
2. 还原测试矩阵（5 场景）每版本必过；改动系统接管相关代码后必须跑。
3. 提交前 `scripts/check.ps1`；改主流程 UI 补 `pnpm e2e`；Rust 侧改动必跑 clippy + test。
   - **跑 Rust 门禁先确认作用域**：`--manifest-path src-tauri/Cargo.toml` 不带 `--workspace` 时只覆盖主包（坑 26）。
   - dev 实例开着时 `target/` 被占锁，用 `CARGO_TARGET_DIR=src-tauri/target-verify` 绕开，别杀正在接管桌面的进程。
4. **每版本发前必跑 `pnpm verify:updater`**，Release 页面确认已 Publish 且 3 个 assets 齐全（坑 25）。
5. **文档与代码冲突时以代码为准**，并回写对应文档（本次 07 即按此重写，03 两处旧口径同步修正）。
