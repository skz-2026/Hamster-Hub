## 2. 近期路线（1-2 周）：收口 M3，发出公开版 v0.2.0

**原则：最值钱的动作不是加功能，是把 M3 剩余项做完、搞定签名，尽快公开发布。**

| 序 | 任务 | 说明 | 依赖 |
|---|---|---|---|
| 1 | 提交 dock 右键菜单收尾改动 | tray.rs / apps.rs / lib.rs / ipc.ts 批次入库，跑 `scripts/check.ps1` 全门禁 | 无 |
| 2 | 通知中心 v1 | 不做复杂：日期 + 小组件堆叠 + 简单通知列表；为 M4 agent 任务完成通知预留接口 | 无 |
| 3 | /files 页面 | 复用 fileindex 已有索引，iOS 风浏览/筛选/最近，去掉 StubRoute | 无 |

## 3. 中期路线（4-6 周）：M4 Agent 原生桌面（拆小步走）

方向决议不变：大脑外置（集成 agent CLI）+ 桌面 MCP 为手脚。M4 整包太大，按风险与依赖排序：

| 序 | 任务 | 说明 | 风险 |
|---|---|---|---|
| 1 | desktop 工具组 5-8 个核心工具 | 启动应用 / 搜索应用文件 / 待办便签 / 音量 / 系统信息；基于 hamster-mcp 扩展 | 低 |
| 2 | `--mcp-config` 会话级注入 | 零侵入用户配置，HTTP 内嵌承载（127.0.0.1 随机端口 + 双令牌） | 低 |
| 3 | 桌面助手会话预设 | 轻量 persona、不绑项目目录；Spotlight「问 AI」路由 bench 会话，微任务走 ai_chat 兜底 | 中 |
| 4 | agent 后台任务 + 通知中心联动 | 任务完成通知点击直达会话（依赖近期第 2 项的接口预留） | 中 |
| 5 | computer use | 截图/点击/键入 + 确认档（每步/仅高危/全自动）+ 急停热键 + 审计与截图留证 + 操作期 UI 宣告。**放最后**，安全机制本身约占一半工时 | 高 |

## 4. 远期路线（v0.4+）

- **增长侧**：
  - 埋点体系（当前为 0；公开版后无数据则无法决策优先级）——本地统计、匿名上报可关；
  - 首发渠道：小众软件 / V2EX / ProductHunt；落地页与双语手册站已就绪可直接用。
- **产品侧**：灵动岛、锁屏、多任务视图、壁纸/主题市场、小组件插件生态、多显示器；M5 再评估 macOS。
- **商业化**：核心永久免费无广告不变；现阶段维持打赏二维码，远期可选 Pro（AI 额度 / 高级主题壁纸），不急。

## 5. 每个里程碑的验收纪律

- 每个里程碑收尾做一次真实用户灰度（10-50 人内测群），用数据决定下阶段优先级。
- 系统接管三件套每版本过「崩溃 / 杀进程 / 断电」还原测试矩阵。
- 所有改动过 `scripts/check.ps1` 门禁（typecheck + build + fmt + clippy + test），主流程 UI 改动补 e2e。
