# 仓鼠Hub（HamsterHub）产品规划

| 项 | 内容 |
|---|---|
| 产品名 | 仓鼠Hub |
| 英文名 | HamsterHub |
| Slogan | 把桌面，囤进一个窝。 |
| 定位（v3 修订） | **Windows 上的 iOS 风格桌面 × Agent 原生**：接管桌面层的模拟器 + 管理工具——iOS 主屏幕（图标网格/分页/文件夹/小组件）+ Dock + Spotlight 搜索 + 控制中心，底层是完整的桌面助手（应用/文件/待办）。AI 采用**集成 agent 为大脑**（Claude Code/ZCode/Codex/Gemini，经 内置代理域层托管），桌面能力以 **MCP 工具**暴露给 agent，并可经 **computer use**（截图/点击/键入/浏览器）操作整台电脑——差异化主张「桌面听得懂话，而且能动」（2026-09-12 方向决议） |
| 形态 | 桌面应用（Windows 优先，Win10 1809+ / Win11），安装后可选「进入桌面模式」 |
| 商业模式 | 核心功能永久免费、无广告；远期可选 Pro（AI 额度 / 高级主题壁纸） |

---

## 1. 背景与机会

### 1.1 市场现状

Windows 桌面效率工具长期分裂成几类，用户往往要装多个软件拼凑体验：

| 竞品 | 强项 | 短板 |
|---|---|---|
| 竞品 A（Windows 桌面工作台，直接对标） | 工作台 + 小组件 + 搜索一体化，颜值高 | 仅 Windows、闭源，功能仍在早期 |
| 竞品 B | 开源 AI 工作站，技术栈同构（React + Rust），内置会话引擎原生 browser-use + computer-use | 形态是「工作站应用」非桌面接管；但其存在证明 computer use 是该赛道真实需求与竞争点 |
| 竞品 C（桌面格子整理工具） | 桌面格子整理老牌稳定 | 广告与推广系捆绑感重，UI 老 |
| 竞品 D（插件化启动器） | 插件生态、搜索启动极强 | 界面偏极客，普通用户上手门槛高 |
| 大而全型安全整理套件 | 功能大而全、装机量大 | 常驻占用高、口碑分化 |

### 1.2 机会点

1. **一体化空白**：把「工作台小组件 + 应用启动 + 文件搜索 + 待办日程 + AI」收进一个高颜值窗口，市面上没有一个既轻量又好看的方案。
2. **本地优先**：隐私意识上升，待办/便签/日程/文件索引全部本地存储、默认不出网，是天然卖点。
3. **Agent 原生（2026-09-12 方向决议升级）**：现有桌面工具普遍没有 AI。仓鼠Hub **不自研 agent 引擎**——大脑复用集成 coding agent CLI（Claude Code/ZCode/Codex/Gemini，经 内置代理域层会话托管与流式通道，能力随上游升级白拿）；手脚是**桌面 MCP server**：把启动应用/搜文件/待办/音量等既有能力包成 MCP 工具，经 hamster-core 的 MCP 配置同步引擎注册进各 agent。OpenAI 兼容问答降级为未装 agent 时的兜底。另外 **computer use 是明确竞争点**（赛道内新品已相继具备）：agent 经截图/点击/键入/浏览器工具操作整台电脑，覆盖自家桌面工具到不了的原生弹窗与第三方应用——上游的 `hamster-mcp` 已有现成实现可直接 vendor。
4. **仓鼠 IP**：治愈系萌宠人设，「囤东西进窝」与产品心智完全一致，利于传播和周边延展（表情包、桌面宠物）。

### 1.3 市场验证与启示

> 综合对同类产品的公开观察与本机实测（细节内部留档，不在此展开）。

1. **产品决策：跟进桌面接管，差异化走 iOS 风**。「Windows 桌面 macOS 化」已被市场验证为可接受的产品形态；仓鼠Hub 以 **iOS 风格**切入——同类产品多走 macOS 风，我们做 iOS 风，目标人群（iPhone 用户、年轻群体）更广且零学习成本。任务栏隐藏、状态恢复、看门狗这套高风险机制**纳为必修工程项**，不回避。
2. **现有产品普遍没有 AI**：搜索仍是「关键词 → URL 模板」形态，无任何 AI 配置。「Spotlight 顺手问 AI」是我们最明确的空档差异点，坚持推进（2026-09-12 升级为 Agent 原生路线，见 §1.2 / §3.2）。
3. **分类分组是核心用法**：主流产品普遍提供分页布局、多组应用/文件预置分类，证实用户按场景整理的心智。iOS 的分页 + 文件夹范式天然覆盖该需求，成为主屏幕的基础能力。

## 2. 目标用户与核心场景

### 2.1 用户画像

| 画像 | 描述 | 核心诉求 |
|---|---|---|
| 效率党小林（25-35，程序员/运营） | 桌面 200 个图标，每天找文件找应用 | 热键呼出搜索，一键启动；待办不丢 |
| 整理控阿珍（30-40，财务/行政） | 文件按项目堆积，强迫症 | 一键整理、分组、最近文件直达 |
| 摸鱼党小王（20-28，学生/职场新人） | 关心热搜、周末、发工资倒计时 | 热榜、倒数日、好看的时钟天气 |
| 颜控设计师阿May | 受不了丑工具 | 毛玻璃、主题、精致小组件 |

### 2.2 核心场景故事

- 早上开机：打开工作台，一眼看到时间、天气、今日待办 3 条、下午 2 点的会议提醒。
- 干活中：`Alt+Space` 呼出搜索，输入「报销」直接命中 Excel 文件回车打开；输入「chat」回车启动微信。
- 摸鱼间隙：工作台右下角刷微博热搜，倒数日显示「距周末还有 2 天」。
- 下班前：勾掉待办，顺手在便签记一句「明天先回张总消息」。

## 3. 功能规划

优先级：P0 = MVP 必须；P1 = 第二梯队；P2 = 远期。

### 3.1 iOS 桌面模拟层（产品主体）

| 功能 | 描述（iOS 范式） | 优先级 |
|---|---|---|
| **主屏幕 Home** | 全屏接管桌面层：壁纸 + 图标网格（圆角方形图标 + 名称）、多分页 + 底部页码圆点 | P0 |
| └ 长按编辑模式 | 图标抖动、拖拽重排/跨页、拖到一起合并文件夹、移除 | P0 |
| └ iOS 文件夹 | 圆角半透明文件夹，点开缩放全屏网格 | P0 |
| └ 小组件 | 网格内嵌时钟/天气/日历/待办/电池（iOS 14 风格小/中组件） | P1 |
| **Dock** | 底部毛玻璃圆角容器，固定 4-6 个常用应用，常驻各页 | P0 |
| **Spotlight 搜索** | 热键呼出（Alt+Space，可改），毛玻璃覆盖层：应用/文件/网页/AI 四路结果 | P0（AI 为 P1） |
| **控制中心** | 右上角热区/热键滑出：Wi-Fi/蓝牙/亮度/音量/勿扰/锁屏 iOS 风磁贴 | P1 |
| **通知中心** | 顶部下拉：日期、小组件堆叠、应用通知聚合 + agent 后台任务完成通知（点击直达会话） | P1（M3 做 v1，M4 联动 agent） |
| **灵动岛** | 顶部居中胶囊：音乐播放/倒计时/下载进度（差异化亮点） | P2 |
| **锁屏** | iOS 风锁屏（时钟+通知），可选 | P2 |

### 3.2 桌面助手内核（支撑层）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 应用索引 | 开始菜单 + UWP 全量枚举、图标提取缓存、启动 | P0 |
| 文件索引与搜索 | 配置目录索引、拼音/首字母模糊、分类筛选 | P0 |
| 待办/便签/倒数日/日程 | 本地存储，小组件 + 独立视图双形态 | P1 |
| 天气 | Open-Meteo 免 key + 城市选择 | P0 |
| Agent 助手（大脑外置，不自研） | 大脑 = 集成 agent CLI（hamster-runtime 托管，GUI 流式对话/PTY/Recall 已就绪）+ 桌面助手会话预设（轻量 persona、不绑定项目目录）；Spotlight / 独立面板双入口 | P0（M4） |
| 桌面 MCP server | 基于上游 `hamster-mcp` 扩展，三组工具：desktop（启动应用/搜索应用文件/待办便签/音量/壁纸/系统信息）+ browser（CDP）+ computer（截图/点击/键入）；**HTTP 内嵌承载**（127.0.0.1 随机端口 + 每会话 Bearer 令牌，随主进程常驻），经 `--mcp-config` 的 `type:"http"` 会话级注入（零侵入用户配置）；高危工具白名单 + 审计日志 | P0（M4） |
| Computer Use | agent 操作整台电脑：xcap 截图（image content 直供视觉模型）+ enigo 鼠标键盘 + CDP 浏览器，覆盖原生弹窗/第三方应用；默认关闭需显式开启（设置页开关即时生效），令牌急停/审计留证/UI 宣告 | P0（M4） |
| AI 兜底问答 | OpenAI 兼容配置（默认引导 GLM）单次调用：未装 agent 的用户 + 微任务分层路由（纯问答不拉起 coding agent） | P1 |
| 文件 App | iOS 风「文件」浏览器（浏览/筛选/最近） | P1 |
| 多任务视图 | 热键呼出运行中窗口平铺（iOS 应用切换器范式） | P2 |
| 设置 App | iOS 风格设置（外观/壁纸/热键/分组/AI/开机进入桌面模式） | P0 |
| 系统接管三件套 | 隐藏任务栏 + 桌面图标、状态快照与恢复、看门狗进程 | P0 |
| 托盘/自启/单实例 | 退出桌面模式一键还原系统 | P0 |

### 3.3 MVP（v0.2.0「桌面模式」）范围

**做**：系统接管三件套（可一键还原）、主屏幕（网格/分页/长按编辑/文件夹/壁纸）、iOS Dock、应用索引与启动、Spotlight（应用+文件+网页）、设置 App 基础项（壁纸/热键/退出模式）、托盘。

**不做（明确砍掉）**：小组件、控制中心、通知中心、灵动岛、锁屏、多任务、AI、待办日程——进 v0.3+。

**MVP 验收标准**：
- 进入/退出桌面模式 ≤ 2s，退出后任务栏与桌面图标**完全还原**（含崩溃场景：杀进程后由看门狗还原）。
- 图标网格 60fps 拖拽（1080p/2K）；分页/文件夹交互符合 iOS 直觉。
- 冷启动 ≤ 2s、空闲内存 ≤ 250MB（含全屏 WebView 壁纸层）。
- Spotlight 5 万文件库 p95 ≤ 100ms。
- 卸载后系统无残留（注册表/任务栏状态干净）。

## 4. 版本路线图

假设 1-2 人小队全职开发。M0-M2 已完成（2026-09-11~09-12，实际节奏远快于规划）。**2026-09-12 方向决议后路线改版：主线从「把桌面做得更像 iOS」转向「Agent 原生桌面」**——iOS 全家桶剩余项（通知中心）提前，灵动岛/锁屏等美化项后置。

| 里程碑 | 周期 | 版本 | 目标 | 关键交付 |
|---|---|---|---|---|
| M0 骨架 | 2 周 | v0.0.x | ✅ 已完成 | Tauri+React 工程、窗口效果、IPC/specta 类型流水线、托盘/自启/CI |
| M1 桌面接管 | 4 周 | v0.1.x | ✅ 已完成 | 系统接管三件套（任务栏/图标隐藏+状态恢复+看门狗）、应用索引、主屏幕网格/分页/长按编辑/文件夹、iOS Dock、壁纸 |
| M2 桌面模式 MVP | 4 周 | v0.2.x | ✅ 已完成（超范围交付） | 原范围全部交付，并提前落地：小组件×6、控制中心（真实音量）、待办/便签/倒数日/日程、AI 兜底问答、贴边常驻任务栏（独立置顶窗）、bench 代理工作台（上游：GUI 流式对话 + PTY + Recall）。公开发布待 M3 代码签名 |
| M3 接管收尾 & 公开发布 | 2-3 周 | v0.2.0 | 可信、可分发 | 任务栏托盘区收尾（右键转发/消闪烁）、通知中心 v1（agent 通知的承载，前置）、/search 与 /files 页面（去 StubRoute）、性能与还原矩阵复验、代码签名 + 自更新灰度 → 首个公开版 |
| M4 Agent 原生桌面 | 4-6 周 | v0.3.0 | 桌面听得懂话，而且能动 | vendor `hamster-mcp` 扩成桌面 MCP server（desktop/browser/computer 三工具组，先 5-8 个核心 desktop 工具）、`--mcp-config` 会话级注入、桌面助手会话预设、Spotlight「问 AI」路由 bench 会话（微任务走 ai_chat 兜底）、**computer use**（截图/点击/键入 + 确认档/审计留证/急停热键）、agent 后台任务 + 通知中心联动、主屏 agent 状态小组件 |
| M5 生态 | 持续 | v0.4+ | 平台化 | 灵动岛、锁屏、多任务视图、壁纸/主题市场、小组件插件、多显示器、macOS 评估 |

每个里程碑收尾做一次真实用户灰度（10-50 人内测群），用数据决定下阶段优先级。

## 5. 非功能目标（产品侧承诺）

| 指标 | 目标值 |
|---|---|
| 冷启动时间 | ≤ 2s（MVP），≤ 1.5s（优化后） |
| 空闲内存 | ≤ 200MB（含 WebView2） |
| 搜索响应 | p95 ≤ 100ms（本地库） |
| 隐私 | 待办/便签/日程/索引默认全部本地，仅天气/热榜/AI 需网络且明示 |
| 兼容 | Windows 10 1809+ 与 Windows 11 全覆盖，DPI 100%-200% |
| 更新 | 支持应用内自更新，静默下载、手动安装 |

## 6. 数据指标

- **北极星**：周活跃工作台天数（用户每周打开仓鼠Hub ≥ 3 天）。
- 支撑指标：全局搜索日均次数、应用启动次数（替代桌面双击的渗透率）、待办创建数、7 日留存、崩溃率（≤ 0.1%）；M4 起增加 agent 会话数、「问 AI → 会话完成」转化率、MCP 工具调用量。
- 埋点原则：本地统计、匿名上报可关，MVP 阶段先不做埋点，靠内测反馈。

## 7. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 系统接管（任务栏隐藏等）崩溃残留 / 兼容性 | 高 | 高 | 状态快照 + 看门狗 + 卸载清理三件套为 P0 必修；每版本过「崩溃/杀进程/断电」还原测试矩阵 |
| 同类产品先发且已验证桌面接管形态 | 高 | 中 | 差异化 iOS 风 + AI 空档 + 更低资源占用；小步快跑 |
| 用户未装 agent CLI / coding agent 冷启动慢、token 成本高 | 高 | 中 | 分层路由：纯问答与微操作走 ai_chat 兜底；首启引导安装与配置；桌面助手会话用轻量预设（不绑项目目录） |
| agent 经 MCP 操作系统的信任边界 | 中 | 高 | 工具白名单分级（高危如杀进程默认关或需确认）+ 调用审计日志；能力可整体一键禁用 |
| computer use 驱动真实鼠标键盘（误操作/抢用户焦点，接管桌面场景放大风险） | 中 | 高 | 默认关闭；确认档位（每步/仅高危/全自动）+ 急停热键一键接管 + 审计与截图留证 + 操作期 UI 宣告「agent 正在操作」；优先结构化路径（UIA/CDP/自家 IPC 工具），坐标点击为兜底 |
| 杀毒软件误报（全屏置底窗口+热键+看门狗） | 中 | 高 | 代码签名证书（M2 前购置）；行为透明化说明页；提交白名单 |
| 性能不达标（索引/内存/拖拽帧率） | 中 | 高 | 性能预算写进验收，M1 起建立基准测试 |
| 1-2 人团队战线过长 | 高 | 高 | 严格按里程碑砍功能；桌面形态与助手内核复用同一套索引/搜索/小组件内核 |
| 热榜等外部接口不稳定 | 中 | 低 | P2 定位，接口层抽象可随时下线 |

## 8. 品牌基调

- 吉祥物：圆滚滚的仓鼠「囤囤」，视觉元素：腮帮子（装满图标）、窝（工作台）。
- 主色：胡萝卜橙 `#FF8A3D`；辅助：奶油棕 `#C8A27A`、深色毛玻璃底。
- 文案语气：亲切、简短、不装萌卖傻。
